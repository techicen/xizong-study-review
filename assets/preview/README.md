# Preview Assets

These SVG previews are lightweight public assets for GitHub README, release notes, and social posts.

- `preview-learning-loop.svg` — the core learning loop.
- `preview-learning-loop-zh.svg` — Chinese version of the core learning loop.
- `preview-document-apps.svg` — platform-adapted note/document review.
- `preview-document-apps-zh.svg` — Chinese version of platform-adapted note/document review.
- `preview-error-diagnosis.svg` — wrong-cause diagnosis.
- `preview-error-diagnosis-zh.svg` — Chinese version of wrong-cause diagnosis.
- `preview-ob-style-inline-audit.svg` — sanitized Obsidian-style inline audit preview.
- `preview-ob-style-inline-audit-zh.svg` — Chinese version of the sanitized inline audit preview.

They are intentionally source-free and contain no real lecture, true-question, answer, explanation, OCR, or personal note content.
