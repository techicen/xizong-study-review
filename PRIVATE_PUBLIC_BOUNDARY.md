# PRIVATE_PUBLIC_BOUNDARY

## Keep Private

- Your actual study notes.
- Your Obsidian vault and review ledgers.
- Paid lecture files and any extracted text from them.
- True-question PDFs, OCR outputs, answer keys, and explanations.
- Files containing local absolute paths.
- Personal learning-state and error-pattern records.

## Safe To Publish

- The sanitized skill instructions.
- Blank templates.
- General workflow boundaries.
- Non-source-specific prompt examples.
- Release checklist and install instructions.
- Schemas for users to process their own uploaded lectures, notes, exercises, and true questions locally.
- General true-question metadata fields and safety rules.

## Practical Rule

If a file contains a full real question collection, a real answer explanation collection, a lecture excerpt, a teacher-specific source, or personal learning state, keep it private.
