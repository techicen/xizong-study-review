# Example 04: Wrong-Question Review

## Prompt

```markdown
Use the xizong-study-review skill.

Please review my wrong-question reflection.
Do not solve a new question. Diagnose why I got it wrong.
```

## User Reflection

```markdown
主题：呼吸困难鉴别

我当时看到“活动后气促”就选了 COPD。
后来发现题干还有“突发胸痛、咯血、长期卧床”。
我觉得是我没背熟 PTE。
```

## Expected Skill Behavior

```markdown
## 当前学习状态

consolidating

## 主要问题

- stem_misread / mapping failure
- examiner trap not recognized

## 错因诊断

这不只是“没背熟 PTE”。真正问题是你把一个常见症状“活动后气促”过早映射成 COPD，没有继续读完题干中的风险条件。

## 出题结构

- 表层诱导：活动后气促，让你想到慢性呼吸系统疾病。
- 关键条件：突发胸痛、咯血、长期卧床。
- 正确路径：先识别血栓风险和急性起病，再考虑 PTE。

## Learning Feedback

- 理解程度判断：疾病知识可能有，但题干条件优先级不稳。
- 是否真正掌握机制链：PTE 的风险因素到临床表现链条需要回扣。
- 是否存在认知断点：存在，断在“题干条件排序”。
- 下一步应该：真题验证前先做鉴别诊断对比。

## 下一步

1. 写一句话区分 COPD 慢性气促与 PTE 急性气促。
2. 下次读题先圈：起病速度、危险因素、伴随症状。
```
