Use them to understand how the skill should behave after installation:

1. `01-copd-note-review.md` — note review with learning-state feedback.
2. `02-feishu-doc-review-table.md` — document-app adapted review table.
3. `03-notion-flowus-review-block.md` — portable block output for Notion/FlowUs.
4. `04-wrong-question-review.md` — wrong-question error diagnosis.
5. `05-decision-engine-sample.md` — fast option-decision format after understanding is stable.
6. `06-sanitized-ob-style-inline-audit.md` — sanitized Obsidian-style inline audit inspired by a private workflow.
7. `07-workbuddy-review.md` — WorkBuddy paste-ready Markdown review with a short handoff checklist.

The examples are not medical advice and are not a substitute for official textbooks, lectures, teachers, or current clinical guidelines.
